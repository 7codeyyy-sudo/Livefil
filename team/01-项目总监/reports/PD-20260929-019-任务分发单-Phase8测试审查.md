## 测试点清单（20 点，总监定稿——交付报告逐点给证据）

### A 组 · 规则契约（NOTIFY-001 后端，点 1–5）

1. **规则 CRUD 正向**：task/routine/review 三类创建与查询、`targetType`/`targetId` 过滤、§1.3 分页 meta、按 userId 作用域隔离（越权读不到他人行）。
2. **`level` 服务端派生只读**：客户端提交 `level` → 400 `VALIDATION_ERROR`（**不静默**）；创建/更新/查询响应回带 task→normal、routine→critical、review→review（映射＝PM 补节 1 唯一准据）。
3. **校验语义三连**：review 类提供 `targetId` → 400；`(targetType, targetId, remindAt)` 重复 → 409；PATCH 可改字段集（`level` 不可改）、非己规则 → 404 **不复用 403**。
4. **单条关闭与删除**：`enabled=false` 停用可再开、行转「已关闭」；DELETE 硬删且 `deliveries.rule_id` 置 NULL（历史交付保留可解释）。
5. **全局关闭零新端点**：走既有 `PATCH /me`（`reminderEnabled`），总闸语义对单条规则生效（分区 4 载体）。

### B 组 · 读时物化与重分类（点 6–8）

6. **物化正向与幂等**：`GET /notifications/pending` 触发到点规则落行（`channel=in_app`、`status=pending`、`level` 快照、`attempt_count=0`、`scheduled_for` 按 `users.timezone` 转 UTC）；**重复读不重复物化**（事务内判重）。
7. **重复与安静时段**：none/daily/weekly 展开正确；跨时区变更**不迁移**已发生历史（如实声明）；安静时段未豁免条目**并入原条顺延、不造新条**（去重第 6 条）。
8. **三类 `cancelled` 重分类**：规则关闭 / 全局关闭 / 目标完成 → `pending`→`cancelled`（同读路径、先作废后物化）；`sent`/`failed` 不可改写；`cancelled` 不出现在 pending。

### C 组 · 待处理 / 忽略 / 查询（点 9–11）

9. **pending 口径**：`status ∈ {pending, failed}` ∧ 未 `dismissed`；等级降序 + `scheduledFor` 升序；`cancelled`/`sent` 排除——**口径甲端到端成立**（全部入、失败留、成功退）。
10. **dismiss**：写 `dismissed_at`、**`status` 四值不变**、重复 dismiss 幂等 200。
11. **deliveries 查询**：`status` 过滤、`onlyRetryable`、keyset 分页 meta。

### D 组 · 第 8 端点 `attempt`（v0.7，点 12–16）

12. **sent 上报**：`status=sent`、`error_code`/`next_retry_at` 置空、**`channel` 翻转 `browser`**（派生第 6 条）、`attempt_count` 服务端 +1、`last_attempt_at` 落值。
13. **可重试失败**（`CONSTRUCT_FAILED`/`DELIVERY_INTERNAL_ERROR`）：递增后 <3 → `next_retry_at`＝30s→90s 指数 + **jitter**（断言落在 ±20% 区间）；≥3 → NULL 停止。
14. **不可重试失败**（`PERMISSION_DENIED`/`UNSUPPORTED`）：`next_retry_at`＝NULL **不再重试**（冻结纪律）。
15. **错误语义五连**：服务端权威字段提交 → 400 不静默；404 不复用 403；终态/达上限 → 409 `CONFLICT`；**带 `Idempotency-Key` 重放 → 409 `IDEMPOTENCY_REPLAY` 不二次递增**；不带 key 自然计数。
16. **FR-071 / 拍板 2 落点**：`failed` 行在 pending 可见且 `errorCode` 回带四值之一——「Notification 权限失败的记录」入库实证。

### E 组 · UI 形态（v0.22 A~D + v0.23，点 17–20）

17. **四渲染点行内展开**：`/inbox` 任务行、`/today`、`/week`（共用触发件）+ `/review` 按钮区；`aria-expanded`/`aria-controls` 同步、同屏至多展开一行、展开焦点移入首输入 / 收起归还铃铛、Enter/Space 触发；编辑器字段次序与冻结交互（Toast「已添加提醒」、**不提供删除**、「提醒总开关已关闭。」+「去开启」→ `/settings` 真跳转）。
18. **面板 B 节**：铃铛 `aria-label="待处理提醒"` + 未读 Badge 计数；条目＝等级 Badge（**文字区分**、仅关键级 `danger`）+ 点行跳转 + 标记已读 / 忽略 / 全部已读；**四态冻结文案逐字**（加载失败/重试/没有待处理提醒）；投递兜底甲口径（失败留置不丢条）。
