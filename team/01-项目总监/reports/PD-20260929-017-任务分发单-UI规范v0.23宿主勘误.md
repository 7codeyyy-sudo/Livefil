## 任务：UI 规范 v0.23（勘误级，改动面严格收窄）

对 §5「提醒与通知补节」A 节做宿主指名更正 + 行内展开形态细则。**除下述各项外，A 节其余原文与编辑器冻结形态零改动**：

1. **宿主更正 3 处**（A 节 L789「位置裁定」句）：
   - 「任务详情」→ **任务行内展开区**，须**至少覆盖两个渲染点：`/inbox` 任务行 + 已排任务行（`/today` 或 `/week`）**——总监可达性裁定：任务经排程离开 inbox，仅 inbox 落点对已排任务不可达，而提醒恰对已排任务最关键；两处可统一为任务行共用触发件（PM 按行组件复用度定稿）；

   - 「`/review` 页内『提醒』按钮展开区」→ **照原文保留**（宿主存在，属待实现入口）。
2. **行内展开形态细则**：触发控件（铃铛图标或等价 affordance，复用既有件优先）、展开交互（行内展开，**不新建路由/抽屉**）、与既有行内动作的共存与可达（键盘、焦点）；**零新增令牌**。
3. **A 节规则编辑器字段与交互零改动**：inline 创建行（时间、重复三选、安静时段 Checkbox 默认不勾、保存 Toast「已添加提醒」）、单条关闭行内开关、不提供删除、总开关关闭禁用态与「去开启」去路——全部照 v0.22 冻结原文，宿主更正不触动其一。
4. 变更记录追加 v0.23 条目（宿主更正缘由与裁定出处：RD-20260929-008 §三 + 本单 + RD-008 文末预审意见第三节）。
