## 状态机

```
主链：草稿 → 待预审 → 待终审 → 执行中 → 已闭环
风险：已上报 → 已决策 → 已闭环
```

---

## 流转路径

```
方案类：出方案 → 总监预审 → 决策者终审 → 下发执行 → 闭环
测试类：研发交付 → 测试验收 → 测试报告 → 总监预审 → 终审 → 研发修复 → 复验 → 闭环
风险类：发现风险 → 即时上报总监 → 总监判断是否同步决策者
```

---

## 变更规则

- 只追加不改写。
- 审查意见、终审结论、执行反馈按时间顺序追加到"变更记录"区。
- 版本过多时顶部加一行摘要。

## 代码权限速查

| 岗位 | 可写 | 禁止 |
|------|------|------|
| 项目总监 | `team/01-/` | 任何代码文件 |
| 产品经理 | `doc/03/`、`doc/04/` | 任何代码文件 |
| 全栈研发 | `src/`、`app/`、`drizzle/`、`scripts/` | `tests/` |
| 测试交付 | `tests/` | `src/`、`app/`、`drizzle/`、`scripts/` |
| 市场行政 | `team/05-/` | 任何代码文件 |
| 商务客服 | `team/06-/` | 任何代码文件 |

铁律：业务代码只有研发岗能改，测试代码只有测试岗能改，其他岗位一律禁止动代码。
