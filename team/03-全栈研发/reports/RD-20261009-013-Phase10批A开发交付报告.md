## 2. 三小批交付摘要

### 2.1 AUTH-001（A-DB）

- **`users` 三列**：`username varchar(30)`（唯一索引、写入 trim+ASCII 小写归一、字符集 `[a-z0-9_一-龥]` 不含 `@`——登录标识单一判定的前提）、`password_hash varchar(160)`、`email_verified_at timestamptz`；**CHECK** `mode='local' OR (email IS NOT NULL AND password_hash IS NOT NULL)`（存量行全 local，零破坏）；**`deleted_at` 不加**（归属批 1，两批各出迁移无同列路径——RD-012 §2.1 裁定落地）。
- **`sessions`**：甲案三要件（可吊销 `revoked_at` / 多设备每设备一行 / `device_label` 卫生截断）；不设 `version`/`updated_at`/`token_hash`（§4.12.1 取舍同族，RD-012 §2.3 终审裁定签名令牌方案）；惰性清理不引 cron。
- **`email_verification_codes`**：HMAC 落库不存明文、单活跃码（同键新发即作废旧码）、`attempts≥5` 作废、`(email,purpose,created_at)` 频控索引。
- **迁移 0008**：纯加表/加可空列/加索引——空库全新迁移与存量升级双路径可执行（对标 DB-001）；journal+SQL+快照三件齐，`ai-migration-0007` 的 forward-only 一致性断言复跑通过。

### 2.2 AUTH-002（A-auth，验收红线本体）

- **门禁（RD-012 §5.2 落点）**：`EnsureLocalSessionUseCase` 构造注入 `mode`（缺省 `local`）——**local 分支逻辑逐字节保持 IAM-001 现状**（既有集成测试零改动通过）；`cloud` 分支走流 4 校验链（验签快拒 → sid+uid 双谓词查行 → 行状态权威 → 半衰点滑动续期重签 → last_seen 节流），**任何失败抛 `AuthenticationError`（401），不重建、不降级**。`APP_MODE` 门禁值来自 `serverEnv.appMode`（缺省 local），经 `resolveSession` 单点收口——**全部 100+ 端点零逐点改动继承红线**。
- **九流时序**（RD-012 §3 全量）：注册（核码原子 → B1 identifier 检查 → 单事务建号播种 → 新会话）、双通道登录（含 `@` 单一判定、统一 401、**登录必换新 sid**）、发码（IP+email 双层频控、存在性分流只在邮件侧）、登出/改密（吊销其余留当前）/重置（全量吊销含当前）/改邮箱双验证、滑动续期、惰性清理。
- **8 端点**（契约 v0.8 #1–8 落地）+ `POST /auth/local/session` 认证部署 ⇒ **403**；本地部署下 8 端点 ⇒ 结构化 **404**（双态总则）。
- **零依赖六件**：scrypt（`N=32768,r=8,p=1`、参数随串、`timingSafeEqual`）、验证码 `randomInt` + HMAC-SHA256 分域派生、进程内滑动窗口限流（单实例边界如实申报）、HTTP 邮件适配器（超时 10s/无重试/502 降级/mock 仅 dev-test 且**生产+cloud+mock 装配期拒绝**）、DB 窗口频控、内存 IP 限流。
- **安全事件扩列**：14 个 authentication 类目事件（注册/核码四态/登录双态/重置请求与完成/改密改邮/登出吊销），全部经 `AuditLogger` 只记结果与匿名标识——对齐 SRS §6.7 扩列注记（L607）与详设 §8.2。

### 2.3 AUTH-003（A-UI）

- **`(auth)` 路由组**：独立布局不挂应用外壳（v0.26 C0）、单列窄栏 **400px**（唯一新布局量，B11 单点定值于 `auth.module.css`，不进 tokens）、零装饰、全令牌；**注册三步**（步 2 仅前端格式校验、核码在步 3 与建号原子——流 1 步 2 理由）、**登录双 Tab**（`aria-pressed` 分段复用 `/review` 先例、不新造 Tab 族）、**忘记密码两步 + 完成态**；冻结文案逐字（失败行/限流行/页顶说明行/步骤 caption/防枚举统一句）；密码规则 helper 满足项转 success（B1 三条与服务端 Zod 同源）。
- **401 同源回跳**（B4/RD-012 §5.3）：`api-client` 增 `setUnauthorizedHandler` 挂点（`setSyncWriteSink` 同款「端口在消费方」）；`SessionGuard` **只在 `(app)` 根注册**——登录页自身 401 只展示不跳转（防循环）；`next` 过 `^\/(?!\/)` 同源校验；同步后台 401 触发跳转而 **IndexedDB 队列不被触碰**（入队只发生在无响应的网络失败路径）——重登录自动续推。
- **设置分区 9（账号）**：**仅 `mode==='cloud'` 渲染**（C4）；邮箱/账号只读行 + 名字修改（`PATCH /me displayName`，非新端点）+ 改密码（当前密码确认，成功吊销其余）+ 改邮箱双验证两步 + 登出置底（**直接执行无确认**，B9）；**双态模式标识**顶部句更正为 v0.26 冻结句（云端态「数据保存在云端并按账号隔离」）。

## 6. AUTH-004 测试点清单（随交付移交测试轨；PD-025 §二 注——`tests/` 归测试岗，本批零触）
