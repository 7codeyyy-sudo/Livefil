## 任务 3：UI-010 登录与账号 UI 形态草案（新补节条文，候终审冻结）

### 3.1 设计方向（最终决策者「前端也要好看高级简约」＋总监方向性约束，逐条挂既有件准据）

1. **复用令牌族即高级**：近黑实心主按钮（§4.1 L380，v0.4 定稿）、surface/focus-ring/radius/shadow 全走 §2.4 在册令牌、状态与加载用 §4.6 页面状态组件——**零新增视觉体系、零新增令牌**。
2. **单列窄栏居中、零装饰**：无插画、无图标装饰、无背景几何（见 3.4 裁定项 d）；对照 §1.1「明确避免」。
3. **一个主按钮一个次操作**（§4.1 L373「每组操作最多一个高强调主按钮」；次/低强调按 L376-378 分级；按钮文案用动词、不用「确定」（L382））。
4. **错误态 inline + focus-ring**：错误信息靠近字段、说明如何修正（§4.4 L408），焦点环取 §2.4 `--color-focus-ring`；失败/限流为表单级 inline 行，不用阻塞式 ErrorState。
5. **加载态静态 Skeleton**（§4.6 L433，零循环动画）；提交时按钮 `loading` 防重复（设置页表单纪律 L826 同款）。
6. **320–767 全宽、暗色预留、零字面量**：断点 §3.1；颜色/字号/时长全走 CSS 变量（§2.4）；唯一新增布局量（auth 窄栏宽）按 §3.2「布局量非设计取值」先例在实现单点定值并披露，**不进组件、不做令牌、数值候 RD-012**。
7. **八态逐页交付**：默认/空/加载/错误/未登录/窄屏/键盘/文案格式（§8 L1127-1136）。
8. **路由组**：建 `(auth)` 独立路由组，**不挂 §3.2 应用外壳**（无侧栏/顶栏/快速添加）；与 `(app)`（L319）并列，容器单列居中。

### 3.2 页面四件（落卷＝新补节条文；字段规则/步骤跳转/参数落地均标**候 `RD-20261009-012` 详设定稿**，本单不虚构）

**① 注册页 `/register`**（三步，同窄栏、步内单表单）

- 结构：步 1 邮箱 →「发送验证码」；步 2 验证码（**单输入框**，`inputmode="numeric"`、`autocomplete="one-time-code"`、长度 6——不造六格 OTP 组件族）→「验证」；步 3 账号 + 名字 + 密码 →「创建账号」。步骤指示用 caption 文本「第 n 步，共 3 步」，**不新造 stepper 组件**；「上一步」为低强调按钮。
- 文案**【冻结候选】**：页题「创建账号」；步 2 说明「验证码已发送至 {邮箱}，10 分钟内有效。」；步 2 错误行「验证码不正确或已过期。」；重发＝低强调「重新发送」+ 限流统一文案「操作过于频繁，请稍后再试。」；页底次操作「已有账号？登录」。
- 密码规则以 helper 文本行列出（满足项转 `success` 色，令牌在册），**规则内容与强度判定候 RD-012**；名字字段必填性与 FR-002 L185 张力见 C5（候详设）；撞名提示 vs 枚举防护归批 A 安全矩阵（候详设）。

**② 登录页 `/login`**（双 Tab：密码｜验证码）

- 结构：双 Tab 用既有分段控件模式承载（`/review` 分段先例），不新造组件族；标识**单框**「邮箱或账号」（档 A，后端判定归属候 RD-012）。
- 密码 Tab：标识 + 密码 → 主按钮「登录」；次操作「忘记密码」；页底「还没有账号？注册」。
- 验证码 Tab：标识 + 验证码（同 ① 单框形态，零新组件）→ 主按钮「登录」；次操作「重新发送」。
- 状态与文案**【冻结候选】**：401 跳转页顶说明行「请先登录后继续。」；密码失败行「邮箱/账号或密码不正确。」（统一、不区分哪项错——防枚举 L108）；限流行「操作过于频繁，请稍后再试。」（429 `RATE_LIMITED`，接口 L81）；**登录失败行只述凭据问题、不暗示数据变更**（R6 约束）；提交 `loading` 防重复；页面首载静态 Skeleton。
- 深链回跳、Tab 默认值、自动聚焦策略**候 RD-012**。

**③ 忘记密码 `/forgot-password`**（两步）

- 结构：步 1 邮箱 →「发送验证码」；步 2 验证码 + 新密码 →「重设密码」；完成态「密码已重设，请用新密码登录。」+ 主按钮「去登录」。
- 防枚举统一响应**【冻结候选】**「如果该邮箱已注册，验证码已发送。」（L108）；验证码输入与 ① 同一形态。
- 新密码规则同 ① helper 行（候详设）；会话失效策略（已登录态访问本页）**候 RD-012**。

**④ 账号设置分区（设置分区 9，仅认证态渲染）**

- 分区信息：标题「账号」；只读信息行（邮箱 / 账号 / 名字）+ 各自修改入口；改邮箱、改密码为**区内 inline 表单 + 分区独立保存**（L813 分区体例 + L826 表单纪律），流程细节（当前密码确认、验证码核验、改后会话策略）**候 RD-012**。
- 「登出」：按钮置分区底部（低强调或危险变体的取舍**候 RD-012**——登出非破坏、无数据删除）；直接登出 vs 轻确认的取舍候详设。
