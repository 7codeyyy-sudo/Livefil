## 结论 / 内容

### 任务 1：《开销与复盘 UI 补节》（UI 规范 v0.21 新章节）

**A. 记账形态（覆盖分发单 A 组 5 条）**

- **A1 入口与容器**：三选一裁定为 **Drawer**（§4.5 冻结件复用，理由三条：≤8 字段短表单、保存后列表与筛选上下文原地保留、独立页留给需 URL 的复杂流程/页内分区失瞬时性）；入口＝`/expenses` 列表上方固定主按钮「记一笔」（承接 §5 总则 1，不随滚动消失，顶栏「＋」既有冻结行为不改）；初始焦点＝金额输入（§4.4）。
- **A2 字段次序与金额优先**：必填四项（金额+币种同行 → 分类 → 日期 → 折叠区前主表单即可保存）+ 可选四项入「更多信息」折叠区平铺；必填标「必填」文本 + `aria-required` 不只用星号；金额只接受 ≤2 位小数、输入框与列表金额列均 tabular-nums（总则 3 同时适用两处）、提交层最小货币单位整数（拍板 4① 整数分铁律）；关联目标或行动＝单选选择器二组至多一项（FR-053），生活领域独立字段。
- **A3 默认与最近使用分类**：新建预选最近使用（无历史预选默认组首项「餐饮」，FR-051 列示序）；选择器分组序＝最近使用（≤3）→ 默认 9 分类 → 自定义（创建时间倒序）；已停用分类不进新建列表、编辑时原值显示带「已停用」Badge 只保持或换新。**「最近使用」数据口径契约未写（`expense_categories` 仅 `is_default`），按分发单授权 UI 先定形态，口径由聚合分发单实现计划披露**（已在 A3 注记）。
- **A4 软删撤销 Toast**（FR-052 撤销路线，对接 DELETE「返回可撤销信息」）：删除 → ConfirmDialog 二次确认（`role=alertdialog`、初始焦点「取消」、危险按钮）→ success Toast「已删除一笔开销」+ 操作槽「撤销」（`--color-accent`、8s 带操作按钮时长，均为 §4.5 既有冻结值）→ 撤销则恢复（清 `deleted_at` 带 version，实现自由度）+「已恢复」+ 行回插；8s 未点则保持软删；**不设回收区**、不做批量删除。编辑复用同 Drawer，PATCH 带 `version`，版本冲突**复用 §4.9.2 冲突浮层**（拍板 1 已将 expenses 纳入冲突白名单）。
- **A5 列表与筛选**：排序唯一口径＝`occurredOn` 倒序 + 同日创建倒序；分页＝既有 cursor 累积 + 「加载更多」；筛选条＝日期范围/分类/生活领域/目标四维可搜索 + 「清除筛选」，变更重置首页；四态＝AsyncState 接线，空态分「无任何记录」（操作「记一笔」＝真实动作）与「筛选无命中」（操作「清除筛选」）两型，不放假按钮。

**B. 复盘形态（覆盖分发单 B 组 4 条）**

- **B1 日复盘**：入口时机＝进 `/review` 即呈现当日、页面内常驻**不自动弹层不打断**（对外提醒属 Phase 8 NOTIFY-001）；`data:null` 落可填写态**不走错误态**（§10 冻结语义）；事实摘要只读区（REVIEW-001「完成和偏差」，空态带真实目标「查看今日计划」）；三问一题一卡与 `answers` 键逐一对位（`completed`/`blocker`/`nextAdjustment`）、**均不标必填**；可选精力三档（对接 `energyLevel`）；**只答一题可保存**（全空时保存禁用 + 辅助文案）、**保存＝PUT 合并已存答案**（只答一题不破坏其余已答）、**跳过＝纯前端不调 PUT 不产生记录** + 「补写今天复盘」恢复。
- **B2 周复盘汇总表**：FR-061 七项逐项落形态（第 1–6 项入「看到事实」段、第 7 项入「做出调整」段）——①计划任务数与状态数值行 ②四态 Badge 单行 ③计划/实际/差值三列数值（**拍板 6 口径：实际＝执行记录开始→完成，未执行不计入**）④重复延期列表（**口径：本周改期 ≥2 次**，拍板 6，无命中行文案）⑤目标行「行动 x/y」⑥开销摘要三小块（**拍板 5：按币种分列跨币种不合计** + 按分类 + 按生活领域，源 `GET /expense-summary`，分次 groupBy 属实现自由度）⑦「下周调整确认」清单（空态行 + 动作 Badge/名称/参数/时间 + 固定链接「查看下周计划」→ 排程页下周，REVIEW-003 验收项）。周切换仅上一周/本周、未来周不可选。
- **B3 洞察就地操作**：洞察＝**前端固定规则生成、无 AI 无新端点**（三条 P0 规则：重复延期≥1、计划任务未执行≥1、目标周进展 0/y，全不命中本段不渲染）；每洞察行尾**唯一入口**「调整」（次按钮）→ 行内展开动作组（任务类：保留/缩短/移到下周/删除；目标类：保留/暂停目标；组内全次按钮无主按钮——确权在弹窗）；**动作集＝FR-062 前五项**，「调整提醒频率」不设入口（拍板 7）。
- **B4 调整确认与可追溯**：每动作必经 ConfirmDialog（五动作各一句后果文案冻结，缩短含单个数值输入、删除危险初始焦点「取消」）；POST `{targetType,targetId,action,payload}` 结构对接，失败＝弹窗内就地 `role=alert` + 重试（模式同 §4.9.2：不关弹窗不清参数）；成功 → 即时入列 B2⑦ 清单 + success Toast「已记录调整」（操作槽「查看下周计划」同去处）；清单**只增不删、本页不撤销**（可追溯＝记录连续，修正靠追加新动作）。
